Câmeras

Cada câmera herda os padrões globais. Campos preenchidos aqui sobrescrevem esses padrões apenas para esta câmera.

MQTT

Broker para publicar eventos e receber comandos. Usado por Home Assistant e outros integradores.

Detectores

Hardware ou software que processa a IA de detecção. Pode ter múltiplos (ex: 2 Corals USB).

Gravação — padrão global

Aplica-se a todas as câmeras, exceto as que tenham override na aba Câmeras.

Snapshots — padrão global

Imagens JPG salvas para cada evento. Aplica-se a todas as câmeras sem override.

Objetos rastreados — padrão global

Lista de objetos que o Frigate procura. Cada câmera pode ter uma lista própria na aba Câmeras.

Objetos suportados: person, car, truck, motorcycle, bicycle, dog, cat, bird, etc.

go2rtc — Streams

Relay de streams. Câmeras podem apontar para rtsp://127.0.0.1:8554/nome em vez de conectar direto — evita múltiplas conexões na câmera física.

Cada linha: nome: url

YAML bruto

Editor de texto completo do config.yml. Ao salvar nesta aba, substitui tudo.
